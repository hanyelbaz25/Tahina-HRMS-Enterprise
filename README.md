# Tahina HRMS Enterprise

## الإصدار 2.1.0 — المستخدمون والصلاحيات

- شاشة لإدارة المستخدمين متاحة لمدير النظام فقط.
- مدير النظام يمتلك جميع صلاحيات الإضافة والتعديل والحذف والاعتماد والطباعة.
- مسؤول الموارد البشرية يمتلك العرض والإضافة والاستيراد والاعتماد والطباعة والتصدير، ولا يستطيع تعديل أو حذف السجلات الموجودة.
- القيود مطبقة في واجهة البرنامج والخادم لحماية البيانات.

## الإصدار 2.0.2

- يمكن لمدير النظام أو مسؤول الموارد البشرية إعادة فتح شهر الرواتب بعد اعتماده.
- بعد فتح الشهر، يمكن تحميل صف أي موظف إلى النموذج بزر **تعديل**، تعديل القيم، ثم حفظه وإعادة اعتماد الشهر.

تشغيل النسخة الأولى:

```bash
docker compose up --build
```

ثم افتح:
- النظام: http://localhost:3000
- توثيق API: http://localhost:8000/docs
- فحص الخدمة: http://localhost:8000/health

حسابات الدخول التجريبية:

- مدير النظام: `admin` / `Admin@123`
- مسؤول الموارد البشرية: `hr` / `HR@12345`

غيّر كلمات المرور وقيمة `TOKEN_SECRET` في `docker-compose.yml` قبل استخدام النظام في بيئة فعلية.

الصلاحيات:

- مدير النظام: إدارة الفروع والموظفين بالكامل.
- مسؤول الموارد البشرية: عرض الفروع وإدارة الموظفين.

تُنشأ الأكواد تلقائيًا عند التسجيل: الفروع بصيغة `BR001` والموظفون بصيغة `EMP0001`.

الحضور والانصراف:

- تسجيل يدوي من شاشة الحضور.
- استيراد ملف Excel من القالب الموجود داخل النظام.
- أعمدة القالب بالترتيب: `employee_no`, `work_date`, `check_in`, `check_out`, `notes`.
- صيغة التاريخ `yyyy-mm-dd` وصيغة الوقت `hh:mm`.

استيراد الموظفين:

- من شاشة الموظفين اختر «استيراد موظفين من Excel».
- الأعمدة: كود الموظف، اسم الموظف، رقم الهوية، الراتب الأساسي، البدلات، الوظيفة، الفرع.
- يمكن ترك كود الموظف فارغًا؛ ينشئ النظام الكود تلقائيًا.
- ينشئ النظام الفروع الجديدة تلقائيًا، ويحدّث الموظف الموجود اعتمادًا على رقم الهوية.

مسير الرواتب:

- الصافي = الراتب الأساسي + البدلات + الإضافي اليدوي - الخصم اليدوي.
- يمكن إدخال الإضافي والخصم يدويًا أو استيرادهما من قالب Excel الشهري.
- قالب المسير الجديد يحتوي على كود واسم الموظف والفرع والشهر وأيام العمل، وأيام ومبالغ الإضافي والخصم والملاحظات.
- قيمة اليوم = الراتب الأساسي ÷ 30، ويُحسب يوم الإضافي بقيمة يوم عادي.
- يقبل شهر المسير كنص `YYYY-MM` أو كخلية تاريخ Excel تلقائيًا.
- أيام الغياب منفصلة عن الخصومات المالية.
- يظهر شعار طحينية في قسيمة الراتب وفي ملف مسير الرواتب المُصدَّر.
- يمكن طباعة قسيمة موظف منفردة بالحجم الكامل، أو اختيار فرع وطباعة قسائم جميع موظفيه دفعة واحدة بحد أقصى 10 موظفين في كل ورقة A4.
- يمكن تصدير مسير الشهر كاملًا إلى Excel.
- يمكن اختيار الفرع وتصدير مسيره إلى PDF بتنسيق A4 أفقي مع إجماليات الرواتب والإضافي والغياب والخصومات والصافي.
- يمكن اعتماد وإقفال مسير الشهر بعد المراجعة لمنع الإدخال اليدوي أو الاستيراد والتعديل، ومدير النظام فقط يستطيع إعادة فتحه.
- شاشة يومية للسلف والأوردرات مع تحديد المصدر (الفرع أو الخزنة أو تحويل بنكي)، وشهر بدء الخصم، وإمكانية الترحيل أو التقسيط حتى 60 شهرًا.
- تظهر مستحقات السلف والأوردرات في المسير للمراجعة، ولا تخصم من الصافي إلا بعد اعتماد الشهر.
- تقرير شهري كامل للموظف يجمع الراتب والحضور والسلف والأوردرات والأقساط، مع الطباعة أو الحفظ PDF.
- سجل تدقيق لمدير النظام يعرض الإضافات والتعديلات والحذف والاستيراد والاعتماد وإعادة الفتح.
- تسجيل الجزاءات والمكافآت يوميًا؛ تظهر للمراجعة في المسير، ثم تُخصم الجزاءات وتُضاف المكافآت بعد اعتماد الشهر.
- البحث باسم الموظف أو كوده داخل القائمة المنسدلة في شاشة الحركات المالية اليومية.
- إدارة الإجازات السنوية برصيد افتراضي 30 يومًا، والمرضية وبدون راتب والغياب غير المبرر، مع البداية والنهاية وتاريخ العودة والاعتماد والرفض.
- تقرير PDF يوضح الموظفين الموجودين في إجازة والعائدين منها بالتواريخ، وربط الإجازة بدون راتب والغياب المعتمد بخصم مسير الرواتب.
- عند البحث عن موظف في الإجازات أو الحركات المالية، تتزامن نتيجة البحث مع كود الموظف المختار لمنع التسجيل على موظف آخر.
- إدارة عقود العمل والإقامات مع أرقام المستندات وتواريخ البداية والانتهاء ورفع PDF أو صورة، وتنبيهات 90 يومًا وتقارير PDF.
- ملفات العقود والإقامات محفوظة في Docker volume مستقل حتى تستمر عند تحديث نسخة البرنامج.
- يدعم مسير الموظف في أكثر من فرع خلال الشهر؛ يحسب كل فرع الأساسي والبدلات بقيمة اليوم × أيام العمل داخله، بحد إجمالي 30 يومًا.
- تُربط كل سلفة أو أوردر أو جزاء أو مكافأة بالفرع الذي حدثت فيه، ولا تؤثر على مسير الموظف في الفروع الأخرى.
- زر تقرير داخل كل صف بالحركات المالية يفتح التقرير الشهري لصاحب الحركة مباشرة لمنع اختيار موظف آخر بالخطأ.

الإيقاف:

```bash
docker compose down
```
